# Workspace contents and provenance

This note was written by the task author to record where each file came from. The survey data files are the NORC General Social Survey cumulative file exactly as the gssr package distributes it, plus a format conversion of it with values unchanged. The scenario documents say so in their first lines.

| File | Format | What it is | Publisher | Source | Pulled | Licence |
|---|---|---|---|---|---|---|
| gss_all.rda | RDA (R data file) | General Social Survey Cumulative Data File 1972 to 2024, Release 3, as packaged in the gssr R package (data/gss_all.rda): 75,699 respondent records, 6,942 variables, every variable stored as numeric codes. The original file supplied by the package. | NORC at the University of Chicago, General Social Survey; packaged by Kieran Healy (gssr 0.9) | https://github.com/kjhealy/gssr (data/gss_all.rda), built from NORC gss7224_r3.dta | 2026-10-07 | GSS data are public use; gssr package MIT (gssr_LICENSE.md) |
| gss_all.parquet | Parquet | The same 75,699 by 6,942 table converted to Parquet by the task author with pyreadr and pyarrow, values unchanged (missing responses of every kind are empty values, as in the RDA file). | as above; conversion by the task author | converted from gss_all.rda | 2026-10-07 | as above |
