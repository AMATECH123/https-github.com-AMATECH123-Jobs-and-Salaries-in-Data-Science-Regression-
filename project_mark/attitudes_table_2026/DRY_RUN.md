# Dry run record

## 2026 attitudes table, first dry run, 2026-10-07
A fresh agent was given only the prompt and an isolated copy of inputs/ (the first version, with trust,
marijuana, Bible, get ahead and suicide among the twenty). It reproduced the golden path in full: WTSSPS on
both years, Taylor linearised errors over VSTRAT and VPSU with each year independent, the 1.96 margin on
unrounded values, all twenty 2016 figures reproduced under WTSSALL (times OVERSAMP for 1987) with none held,
OVERSAMP not carried onto WTSSPS (it found the adjustment already embedded), the largest restatement (Democrat,
44.7 to 43.6), the decade mover (welfare, +13.9), the closest call (death penalty, 0.20 points, 61.9 instead
of 62.1), Research's draft as the simple random sampling reading and the editor's as the mixed weight reading.

It also found a real problem the golden had missed: in 2024 NORC fielded TRUST, GRASS, BIBLE and GETAHEAD
only to in person and phone respondents, with experimental versions on the web, so their 2024 figures rest on
half the sample; it held those four as not updated and certified 8 moved instead of 9. Ten experts would not
converge on that call, so the five affected indicators (the four plus SUICIDE1, which reached only part of the
web sample) were replaced with items fielded to the whole 2024 sample: health excellent, confidence in
television, moderate, lower class, America a better country. The golden set is still 9 moved; Research's
draft stays at 15 and the editor's becomes 10. A second dry run on the final package follows.
