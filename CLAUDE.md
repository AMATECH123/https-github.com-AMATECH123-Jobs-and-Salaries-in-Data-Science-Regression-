# Repository guide

This repository hosts two unrelated bodies of work:

- The original Data Science salary regression project (see `README.md`).
- **Project Vertex** in `vertex/`: writing multi-hop finance reasoning questions and verified answers.

When working on Project Vertex, read `vertex/INSTRUCTIONS.md` first and run
`vertex/CHECKLIST.md` before calling any question complete. The two
non-negotiable rules are accuracy (every fact exactly as published, verified
twice from the source) and time-insensitivity (nothing that can change). The
verdict is decided by chained retrieval hops: 3 minimum, 4 to 6 goal.
